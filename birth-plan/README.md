# תכנית לידה — שאלון אינטראקטיבי

שאלון תכנית לידה בסגנון Typeform (שאלה אחת בכל מסך, עברית RTL, מקלדת: Enter להמשך, אותיות לבחירה).
מבוסס על מבנה טופס קליטת הנכסים של אפיק הנחל, עם שאלות מתוך מסמך "תכנית הלידה".

**בסיום מילוי:**
1. התכנית נשלחת אוטומטית במייל ליוגב (`/api/birth-plan`, ברירת מחדל `kidaryogev@gmail.com`).
   אם השליחה נכשלת, מוצג כפתור "שליחה ליוגב במייל" (mailto) כגיבוי.
2. מוצג כפתור "שליחה להדס בוואטסאפ" שפותח צ'אט עם הדס הדולה, עם כל התכנית כתובה בהודעה, וכפתור התקשרות.
3. אפשר להדפיס / לשמור את התכנית כ־PDF.

טיוטה נשמרת אוטומטית בדפדפן — אפשר לעצור ולהמשיך.

## הרצה

```bash
cd birth-plan
npm install
npm run dev      # פיתוח
npm test         # בדיקות סכמה ותבנית המייל
npm run build
```

## פריסה ל-Vercel

Root Directory: `birth-plan`. משתני סביבה (ראו `.env.example`):

| משתנה | תפקיד |
|---|---|
| `GMAIL_USER` | חשבון Gmail ששולח את המייל |
| `GMAIL_APP_PASSWORD` | App Password של החשבון |
| `PLAN_EMAIL_TO` | נמען (ברירת מחדל: יוגב) |
| `VITE_DOULA_PHONE` | הטלפון של הדס, ספרות בלבד בפורמט בינלאומי (`9725…`) |

## קבצים

- `src/schema.js` — כל השאלות, הסעיפים, ולידציה ובניית טקסט התכנית (משותף לדף ול-API)
- `src/BirthPlanForm.jsx` — הטופס עצמו
- `src/config.js` — המייל של יוגב והטלפון של הדס
- `api/birth-plan.js` — שליחת המייל
