# 7. סקירת המערכת הקיימת – בעיות עיצוב ושימושיות (לפני השדרוג)

הסקירה בוצעה על גרסה 1 של הממשק (Jinja2 + CSS אחד) ברוחבים 320–1280px, לפי סעיפי אפיון העיצוב.

## מה נשמר בכוונה
* מסכים מרונדרים בשרת (בלי SPA): טעינה מהירה גם במכשירים ישנים, עובד ללא JS למעט נוחות.
* הלוגיקה העסקית והנתיבים לא השתנו (למעט הוספת פרמטרי תצוגה/סינון).
* כל הטקסטים בעברית תקנית; אין אנגלית בממשק למעט מזהים טכניים.
